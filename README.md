# simple-neural-network

A small neural network library written from scratch in Java in 2020, as a learning project.
No ML libraries, only arrays and loops.

Implemented by hand: feed-forward layers, backpropagation, SGD with momentum, dropout,
several activations and loss functions, weight initialization, save/load,
and an LSTM with a text generation example.

This is old study code and it is not maintained. I keep it as a record of where I started.

MNIST in CSV for the [digit recognition example](/src/ru/vladefined/examples/NumberRecognition.java):
https://www.kaggle.com/oddrationale/mnist-in-csv
